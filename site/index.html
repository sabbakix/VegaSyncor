Network folder backups

VegaSyncor is a Linux service that periodically syncs SMB/CIFS shares (Windows PCs and servers, or Samba) to a backup server and off-site to OneDrive. You manage it from a fast terminal interface that works over SSH.

Built for safety first

A backup tool should never be the thing that loses your data.

Kernel-enforced read-only source

Source shares are mounted with mount.cifs -o ro. No configuration mistake can change or delete a file on the source.

Empty-source protection

If a source turns up empty, after a failed mount or an emptied share, the mirror is blocked so the backup is never wiped.

Encrypted credentials

Passwords are stored with AES-256-GCM and never appear in processes, logs or the interface.

Dry run before anything

See exactly what would be copied, updated or deleted before a job ever runs for real.

Features

Everything a small-office backup server needs

Three copy modes

Mirror + archive keeps deleted and overwritten files for N days. Mirror makes an exact copy. Add only never deletes anything.

Flexible scheduling

Run at intervals within a time window, at set times, on chosen weekdays, from a cron expression or manually. The server clock is always on screen.

Incremental with rsync

Only the differences are copied. Set bandwidth limits and exclusions, and turn on checksum comparison for critical folders.

Any destination

A local disk, a USB drive, a mounted NAS, another SMB share or OneDrive, optionally encrypted on the client.

Built-in firewall

Lock the server down to SSH from admin hosts and SMB to the backed-up hosts. Changes roll back automatically if they aren't confirmed.

Export & import

Move the whole configuration, passwords included, to a new server in one file protected with Argon2id and AES-256-GCM.

History & detailed logs

Every run is recorded. Filter logs to show new, updated, deleted or moved files, and search them as you type.

Keyboard & mouse TUI

Every tab, field and command can be clicked. It works over SSH, in true colour, in English and Italian.

How it works

Your first backup in three steps

  1. 1

    Add a connection

    Enter the PC or server address and its credentials. Press t to test access and list the available shares.

  2. 2

    Create a sync

    Pick the share and folder, a destination, a mode and a schedule. A summary box always shows source → destination.

  3. 3

    Dry run, then relax

    Press s for a dry run and l to review the files. Then let the scheduler take over.

Off-site copy

Send a second copy to OneDrive, encrypted before it leaves

OneDrive Personal and Microsoft 365 / Business work as a destination with the same modes, archive, dry run and logs. You can also use OneDrive as a source to restore or check an off-site copy.

  • Sign in from the TUI. No Azure or Entra ID setup needed
  • Optional client-side encryption of file contents and names
  • Restores keep empty-source protection and never change the OneDrive side
  • The sign-in token is stored encrypted and refreshed automatically

Install

Up and running in a minute

Quick install

This detects amd64 or arm64, verifies the package checksum, installs dependencies and starts the service. Run it again to update.

curl -fsSL https://github.com/sabbakix/VegaSyncor/releases/latest/download/vegasyncor-install.sh | sudo sh

With the .deb package

sudo apt install ./vegasyncor_<version>_amd64.deb

From source (Go ≥ 1.26)

make build && sudo ./install.sh

After installing, back up /etc/vegasyncor/master.key somewhere safe. Without it, saved passwords can't be decrypted.

bash
# open the interface
$ sudo vegasyncor

# short status of the jobs
$ sudo vegasyncor status

# check the system can mount SMB shares
$ sudo vegasyncor check

# run a job now, or preview it
$ sudo vegasyncor run "Accounting"
$ sudo vegasyncor dry-run "Accounting"

# move to a new server
$ sudo vegasyncor export
$ sudo vegasyncor import FILE.vsconf

# service log
$ journalctl -u vegasyncor -f

Runs on Debian and Ubuntu (amd64, arm64), on bare metal, VMs, privileged LXC containers (Proxmox) or Docker with --privileged.
